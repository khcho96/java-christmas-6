# 미션 - 크리스마스 프로모션

## 기능 구현 목록
> 기능 작동 순서대로 작성

1. 환영 메시지 출력
   - 안녕하세요! 우테코 식당 12월 이벤트 플래너입니다.
2. 날짜 입력 및 검증
   - 예외 사항
     - 1 이상 31 이하의 숫자가 아닌 경우 -> Validator
       - 유효하지 않은 날짜입니다. 다시 입력해 주세요.
3. 주문 메뉴 및 개수 입력 및 검증
   - 예외 사항
     - 잘못된 형식인 경우(메뉴의 개수가 1 이상의 숫자가 아닌 경우 포함) -> Validator
       - 유효하지 않은 주문입니다. 다시 입력해 주세요
     - 고객이 메뉴판에 없는 메뉴를 입력하는 경우 -> Menu
       - 유효하지 않은 주문입니다. 다시 입력해 주세요
     * 중복 메뉴를 입력한 경우 -> Customer
       * 유효하지 않은 주문입니다. 다시 입력해 주세요
     * 음료만 주문한 경우 -> Customer
       * 음료만 주문할 수 없습니다. 다시 입력해 주세요
     * 메뉴를 20개 초과해서 주문한 경우 -> Customer
       * 메뉴는 한 번에 최대 20개까지만 주문할 수 있습니다. 다시 입력해 주세요
4. 이벤트 대상(총 주문 금액이 10,000원 이상)인지 확인
5. 이벤트 대상이 아닌 경우
   1. 증정 메뉴, 혜택 내역 모두 없음으로 처리 및 결과 출력으로 이동
6. 이벤트 대상인 경우
   1. 날짜에 해당하는 이벤트 반환
   2. 각 이벤트별 할인 적용
      1. 크리스마스 디데이 할인
         - 1,000원으로 시작하여 크리스마스가 다가올수록 날마다 할인 금액이 100원씩 증가
      2. 평일 할인(일요일~목요일)
         - 디저트 메뉴를 메뉴 1개당 2,023원 할인
      3. 주말 할인(금요일, 토요일)
         - 메인 메뉴를 메뉴 1개당 2,023원 할인
      4. 특별 할인
         - 총주문 금액에서 1,000원 할인
      5. 증정 이벤트
         - 할인 전 총주문 금액이 12만 원 이상일 때, 샴페인 1개 증정
7. 결과 출력
   - 날짜
   - 주문 메뉴
   - 할인 전 총주문 금액
   - 증정 메뉴
   - 혜택 내역
   - 총혜택 금액
   - 할인 후 예상 결제 금액
   - 12월 이벤트 배지
     - 5천 원 이상: 별
     - 1만 원 이상: 트리
     - 2만 원 이상: 산타
